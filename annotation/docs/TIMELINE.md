# Flexible plan: A, then B, then C

Everyone works through the same rounds. No Friday work or exact-hour deadlines are planned.

| Stage | Suggested focus |
|---|---|
| Weekend / Monday discussion | Agree on starting rules, discuss calibration questions, and begin A as time allows. A does not need to be finished before Monday. |
| Round A | Each person independently annotates all 169 cases, then we compare and review A together. |
| MVP checkpoint | Assess the reviewed eligible subset of A as a smaller MVP pool, roughly 170 candidates before filtering. Check actual class and split counts before model evaluation. |
| Round B | Each person annotates the same next 169 cases, then we compare and review B. |
| Round C | Each person annotates the remaining 168 cases, then we compare and consolidate across rounds. |

Set the pace together after seeing how long A takes. If time is tight, a carefully reviewed A-only MVP is an option; B and C can expand it later. Keep pending work visible rather than rushing exclusions or calling LLM agreement human review.

The previous individual batch ownership and required five-case ring review are superseded. Existing `SUNDAY_PILOT.md` files remain optional practice inputs and are not deadlines or extra cases. Follow the [current README](../README.md) for the active workflow.
